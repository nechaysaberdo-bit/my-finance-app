# My Finance Native

A React Native + Expo starter for a private personal finance app.

## Run it
1. Install Node.js on your computer.
2. Unzip this project.
3. Open Terminal in the project folder.
4. Run `npm install`.
5. Run `npx expo start`.
6. Install Expo Go on your iPhone and scan the QR code.

This first build contains navigable screens for Home, Transactions, Income, Expenses, Credit Cards, Card Details, Installments, SOA, Loans, Lend/Borrow, Bills and Settings.

Current data is sample data only. The next engineering phase should add local persistence (SQLite), editable forms, billing-cycle calculations, and authentication.
